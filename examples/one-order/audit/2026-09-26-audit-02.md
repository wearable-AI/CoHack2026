## New findings

### NEW-1. "has the order at 3.9 ms" states a moment; the evidence gives an interval

```sh
jq -r '... PlaceOrder span: tags and timed events ...' evidence/02-jaeger-trace-a4013e836e1b.json
```
```
PlaceOrder start 3.865 ms dur 71.977 ms
  tag demo.order.id=7c8c01c4-ba22-11f1-903b-b295684fc89c        (a span attribute: carries no time)
  event at 4.112 ms: feature_flag.evaluation ...   event at 46.214 ms: prepared
  event at 52.322 ms: charged ...                  event at 53.726 ms: shipped ...
```
The order id is a span attribute, and attributes carry no time. None of the timed events names the
id. The first timestamped record of the id is checkout's log line `order placed` at 58.9 ms. So
the evidence places the id's existence between 3.9 ms (the start of the span that carries it) and
58.9 ms. DERIVATION section 3 states the rule ("the first span tagged with the order id"). The
frame says "has the order at 3.9 ms" without it.
Does not change what the clip says: every checkout time in that interval is before the publish at
74.9 ms, so the order of events and every join still hold.

### NEW-2. The first burst runs 5.1 ms under one clock value

`census2.py`: `clock stops at 1.1  lights: frontend-proxy->frontend (1.1), frontend->checkout (3.9),
checkout->cart (6.0), cart->redis (6.2)`. Each edge is within 3.0 ms of the one before, so all four
join one burst. Frames at t = 3.5 to 4.5 s read `t = 1.1 ms` while checkout, cart and redis light.
Board 2 then says checkout has the order at 3.9 ms. The mismatch is at most 5.1 ms. It does not
change what the clip says.

### NEW-3. "the shopper's own span was never exported" is not measured

DERIVATION section 0 and README ("The robot shopper's whole session shares one trace"). The
evidence shows only that Jaeger's answer lacks the 7 parent spans. Whether they were never
exported, were dropped or sampled, or went to another backend is not in `evidence/`. Neither is who
made the calls. This is text only, not on screen. It does not change what the clip says.

### NEW-4. The 1970 fallback records when the collector saw the line, not when it happened

```
currency  conversion successful  observed 332.9 ms  span 7af29f68 start 19.2
currency  conversion successful  observed 333.0 ms  span 017e6c7f start 28.5
currency  conversion successful  observed 333.1 ms  span 8f22940b start 45.1
shipping  Requesting quote       observed 708.3 ms  span ab43edfe start 34.2
```

The six lines cite spans that ran at 19.2 to 53.3 ms. The fallback puts them at 332.9 to
